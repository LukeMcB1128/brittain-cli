# brittain-cli

A lightweight, terminal-first coding agent — the CLI edition of
[Brittain Code](https://github.com/LukeMcB1128/brittain-code).

> Work in progress. See [PLAN.md](PLAN.md) for the build plan.

```bash
npm i -g brittain-cli
brittain --help
```

Requires Node 22 or newer. No runtime dependencies.
